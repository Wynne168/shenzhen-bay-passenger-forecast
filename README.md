# 深圳湾口岸每日入境客流预测

本项目使用香港入境事务处公开的每日旅客流量统计，预测深圳湾口岸每日入境总人次。研究比较不同模型的预测表现，检验加入香港及中国内地节假日特征后的误差变化，并分析高峰日的低估情况。

## 数据与实验设计

- **预测目标**：深圳湾口岸每日入境总人次。
- **数据来源**：香港入境事务处「每日旅客流量统计」。
- **训练集**：2023-03-06 至 2024-12-31，共 667 天。
- **验证集**：2025-01-01 至 2025-12-31，共 365 天。
- **最终测试集**：2026-01-01 至 2026-10-30，共 303 天。
- **比较方法**：上周同日客流基准、Ridge 回归、随机森林和梯度提升。
- **评价指标**：MAE、RMSE，以及高峰日低估率。

## 主要结果

在 2026 年测试期，加入节假日特征的 Ridge 回归在该阶段纳入比较的方法中取得最低的 MAE（6,465.04 人次）和 RMSE（9,443.72 人次）。上周同日基准的 MAE 为 10,874.82 人次。

在 169 个实际高峰日中，含节假日特征的 Ridge 回归有 68.05% 的日期预测值低于实际值。报告进一步检查了低估较大的日期及其入境旅客构成。

## 实验文件怎么用

| 文件 | 用途 |
| --- | --- |
| `notebook/` | 查看从原始数据读取、特征构建到模型评估的完整过程 |
| `data/raw/statistics_on_daily_passenger_traffic.csv` | 原始客流数据，运行 Notebook 时使用 |
| `test_metrics_2026.csv` | 查找测试集的总体、高峰日和非高峰日误差，用于报告结果表 |
| `test_predictions_2026.csv` | 查找每天的实际值、预测值及误差，用于复核个别日期 |
| `peak_case_traveller_composition_2026.csv` | 查找重点低估日期的旅客构成，用于误差讨论 |
| `test_actual_vs_predicted_2026.png` | 2026 年实际客流与预测客流对比图，可用于报告或演示 |

## 如何运行

用 VS Code 打开项目文件夹，选择 Python 环境，确认原始 CSV 位于 `data/raw/`，然后打开 `notebook/` 中的项目 Notebook，按顺序运行所有单元格。只需要写报告或核对数字时，可以直接打开上表中的结果文件。
